# Task 1 - Titanic Survival Prediction

## 📌 Project Overview

This project is part of the CodSoft Data Science Internship.
The objective is to build a Machine Learning model that predicts whether a passenger on the Titanic survived or not.

## 🎯 Objective

To predict the survival of Titanic passengers using information such as:

* Passenger class
* Age
* Sex
* Number of siblings/spouses
* Number of parents/children
* Fare

## 📊 Dataset

The Titanic dataset contains information about passengers who travelled on the Titanic.

The target variable is:

* **Survived = 1** → Passenger survived
* **Survived = 0** → Passenger did not survive

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Google Colab
* Jupyter Notebook

## 🔄 Steps Performed

1. Loaded the Titanic dataset.
2. Checked the dataset and missing values.
3. Cleaned the missing data.
4. Removed unnecessary columns.
5. Converted categorical data into numerical values.
6. Divided the data into features and target.
7. Split the dataset into training and testing data.
8. Built a Logistic Regression model.
9. Made predictions on the test data.
10. Evaluated the model using accuracy, confusion matrix, and classification report.

## 🤖 Machine Learning Model

**Logistic Regression** was used to predict whether a passenger survived or not.

## 📈 Result

The model achieved an accuracy of approximately **81%** on the test dataset.
