# Task 3 - Iris Flower Classification

## Project Overview

This project is part of the **CodSoft Data Science Internship**. The objective of this project is to build a Machine Learning model that classifies Iris flowers into different species based on their flower measurements.

The project uses the **IRIS.csv** dataset and a **Logistic Regression** model for classification.

## Objective

To classify Iris flowers into three different species using:

* Sepal Length
* Sepal Width
* Petal Length
* Petal Width

## Dataset

The dataset used is **IRIS.csv**.

It contains measurements of Iris flowers and their corresponding species.

The three species are:

* Iris-setosa
* Iris-versicolor
* Iris-virginica

## Technologies Used

* Python
* Pandas
* Scikit-learn
* Matplotlib
* Google Colab
* Jupyter Notebook

## Steps Performed

1. Imported the required Python libraries.
2. Loaded the Iris dataset.
3. Checked the dataset information.
4. Checked for missing values.
5. Selected the flower measurements as features.
6. Encoded the species into numerical values.
7. Split the dataset into training and testing data.
8. Built a Logistic Regression model.
9. Trained the model using the training data.
10. Predicted the flower species for the test data.
11. Evaluated the model using accuracy.
12. Created a confusion matrix.
13. Compared actual and predicted values using visualization.

## Machine Learning Model

**Logistic Regression** was used to classify the Iris flowers into their respective species.

## Result

The model achieved:

**Accuracy: 100%**

The model correctly classified all the samples in the test dataset for this train-test split.
